## Shape

**One pair reader.** A private `DrawRange` method returns the run-asked `(drawn, asked)` pairs, the list `follows_ask` builds inline today. Its three readers are `follows_ask` (unchanged result), the capped floor and the evidence state.

**Carry 0, the capped floor.** A module function in `draw_range.py`, taking the window (or none) and the live parameters, returning kW:

    floor = params.flow_lift_power_floor_kw
    if draw is not None and params.min_electrical_power > 0 and len(run-asked pairs) >= MIN_SAMPLES:
        floor = max(on_threshold_kw(params), min(floor, percentile(run-asked draws, LOW_PERCENTILE)))

`MeasuredCop.judge_floor` gains the window as an argument and reads the function; `coordinator._fold_flow_lift` (`coordinator.py:960`) and `accuracy.diagnostics_view` (`power_floor_kw`) read the same function with the same window object, `coord._accuracy.draw`. The cap is the low end itself, not 0.8 x it: the percentile already discards a tenth of the samples.
Invariants, each a test: (a) the result never exceeds `flow_lift_power_floor_kw`; (b) never below `on_threshold_kw`; (c) no window, or fewer than `MIN_SAMPLES` run-asked pairs, is bit-identical to base; (d) no sample asked under the configured minimum moves the result, whatever its draw; (e) a changed configured range clears the window (`DrawRange.observe`), so the floor reverts; (f) with no modulation floor configured the nameplate third stands uncapped (every ask would qualify, and nothing is overstated).
Expected values, (spike), 14 kW nameplate unless said, window of 60 pairs with asks cycling 3.0, 3.5, 4.0, 4.5, 5.0 on a 3.0 kW minimum: draws 0.6 x ask give 1.8 (base 2.4); draws 0.3 x ask give 1.5, the threshold (low end 0.9); draws equal to ask give 2.4. Measured limits: the cap cannot go under 0.5 x an overstated minimum; and a correctly configured pump that cycles on its own controller under a run ask, on a meter that averages, lowers its own floor once such samples pass a tenth of the run-asked pairs (1.0 kW install, 12 of 100 run-asked samples drawing 0.6: floor 0.6 against 0.8; 8 of 100: 0.8), never under (b).

**Carry 1, hold-then-replay.** A second module function in `draw_range.py` returns the evidence state: *follows* and *does not follow* exactly where `follows_ask` is True and False; *unobtainable* where no window is passed (the default of `_learn_measured_cop`, `coordinator.py:5313`), or `MIN_SAMPLES` run-asked pairs exist and their asks do not span `FOLLOW_ASK_SPAN`, or the window is full (`WINDOW` samples) with fewer than `MIN_SAMPLES` run-asked pairs; *pending* otherwise. (spike): a full window asked under a 3.0 kW minimum holds 0 run-asked pairs, one with every tenth ask at 3.2 holds 34; both read unobtainable, where `follows_ask` reads None.
`judge_ratio` becomes an instance method taking the interval's row; order unchanged, one branch changed. A departure beyond `COP_ASK_TOLERANCE`: follows folds; unobtainable keeps base's rule (`nameplate_power_floor_kw` cleared by ask and draw folds, else `COP_REFUSED_NO_EVIDENCE`, `accuracy.py:917`); pending appends the row to the hold and returns `COP_REFUSED_NO_EVIDENCE`. The hold is a deque on `MeasuredCop` bounded at `draw_range.WINDOW` rows; a row is what `_fold_cop_evidence` consumed plus what it was read against: commanded kW, metered kW, the reference tuple from `_cop_reference_curve`, `_cop_scale` at hold time, the instant. Not persisted (`as_dict` unchanged, no `store.py` row): a restart drops the rows.
A release method on `MeasuredCop`, called from `_learn_measured_cop` once per cycle after the interval's own refusal is written, is the only place a held row is judged. It returns rows to fold, oldest first: all of them on *follows*; none, clearing the hold, on *does not follow*; on *unobtainable* the rows base's rule folds, clearing the hold; on *pending* only the rows older than the window's stated horizon (a week, one constant beside `COP_ASK_TOLERANCE`), judged by base's rule. A row the full deque pushes out is judged by base's rule the same way, not lost. The coordinator folds each returned row through `_fold_cop_evidence` with the row's stored scale as `cop_evidence`'s scale argument, discards that call's return value (the interval's own code stays on `MeasuredCop.refusal`), and lets `_cop_samples` rise per folded row.
Invariants: (g) a held row leaves the hold in one of four ways only: folded on *follows*, dropped on *does not follow*, judged by base's rule (unobtainable, a week old, or pushed out), or lost to a restart; (h) with a window that never reaches evidence, every interval base folds is folded, at its own tick or at a release; (i) no interval folds twice; (j) a row folds against the scale it was read at. `diagnostics_view` gains the held-row count beside `draw_follows_ask`.
