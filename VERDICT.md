## Block

1. **class-open: the follow-up's "previous windows" are lost whenever the sensor goes unavailable.** The blueprint takes the announced windows from `trigger.from_state.attributes.cheaper_windows`. `WoodCheaperBinarySensor.available` is `super().available and fuel.get("ready")` (`binary_sensor.py:321-323`), so a coordinator `UpdateFailed` or an integration reload makes it `unavailable`. HA writes an unavailable state without the extra attributes. On recovery the `cheaper_windows` attribute changes from absent to the list, the `replan` trigger fires, `old` is `[]`, and every window that has not opened yet counts as new. Probe (`ev/followup_probes.txt`, the PR's own `_run` harness, which `ev/probe_wood_advisor.py` extends without changing it): at 10:00 with the windows unchanged, `from_state` with no `cheaper_windows` gives **sent = True**. A transient price-API failure or an options save between the send time and 21:00 therefore sends the day's notification again. This is the same follow-up rule round 1's reshape finding covered: a follow-up only for a genuinely new window. The body disposes of reshapes but not of a previous state that has no attribute. The smallest fix is one condition: require `trigger.from_state` to exist and its state not to be `unavailable`/`unknown`. Then add a check that drives the unavailable → on transition and expects silence.
2. **mutation-vacuous: `- "{{ trigger.id == 'daily' }}"` deleted → `ALL 29 wood-advisor checks PASSED`** (`ev/mutants.txt`). The body's rule is "one mutant per blueprint condition", and its table has none for the daily branch. The daily check's fixture (06:00, with a 17:00 window ahead and the follow-up on by default) also passes the replan branch, so the check cannot tell the two branches apart. Under that mutant, an install with **Follow up after a replan** off never gets its daily notification, and neither does any day whose windows have all opened by the send time. A daily-send check with `notify_on_replan=False` (or with every window already open at the send time) would kill it.
