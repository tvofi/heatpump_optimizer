# Security

Private vulnerability reporting is already enabled on this repository.

Do not open a public issue for a vulnerability.

Report it through GitHub's private advisory form:

https://github.com/tvofi/heatpump_optimizer/security/advisories/new

That is the Security tab, then Advisories, then Report a vulnerability.

Include the affected version (`VERSION` at the repository root), what happens, and enough to reproduce it.

Fixes ship in a release of the integration. The supported line is the latest `v*` tag.
