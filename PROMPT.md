(F1, §3.1 L240-251) With heating mode 10000 = 1, register 10001 is the return set-point and replaces the heating curve. So `space_setpoint_unit: return` is established for this controller. Bearing: the note's W is unrounded and accumulates, but its clamp is HPO's own [max(inlet - 1 K, gate + step), ceiling]. A W beyond the controller's clamp is cut silently, so the note must say how it stops W winding up (above the return limit) or down (below parameter 979, which can also stop the wind-down from reaching inlet - 1 K).
(F2, §2.2 note L209, §3.1 item 6 L252) A stopped compressor gets a heating demand only when the return falls below set-point minus the heating hysteresis. That threshold is input 10107, "heating demand border", and is readable. The hysteresis is a controller parameter, 0.5 to 6 K; it was 2 K on the install until set to 0.5 K for the runs. So inlet + 0.5 K does not start a stopped pump unless the hysteresis is at its 0.5 K minimum. Bearing: the note's pseudocode comment "today's write: start past hysteresis" and invariant I3 (first write equals today's) assume today's write starts the pump. At the default hysteresis it does not. The note states which it keeps: today's start write, as a recorded limitation with a user-docs line on hysteresis, or a start write aimed past 10107. The brief's "no new read path" applies to the second, which makes it a design change, not a fixer choice.
(F3, §5 item 4 L331) Every temperature set-point and offset has a 0.1 K resolution in firmware. A 0.5 K step is an integration choice, and ha-luxtronik-shi now uses 0.1. A loop with a 0.5 K deadband or step dithers on this hardware. Bearing: consistent with the note's 0.1 K main simulation and its 0.5 K quantization repeat. No deadband is in kelvin.
(F4, §4 L307-314) SHI values are volatile. After 600 s with no Modbus access to the SHI, and after every controller restart, all SHI-set values revert: the modes to 0 and the set-points to their defaults (10001 -> 35.0 °C). Any access re-arms the timer, a read included. Bearing: the deadband branch holds W unchanged.
