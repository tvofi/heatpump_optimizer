# SweClockers x ASUS, "Gick inte. Nu går det." Rules notes

Read 2026-10-22 from four pages:
- https://projekt.sweclockers.com/asus/utmaningen (overview)
- https://projekt.sweclockers.com/asus/villkor (full terms)
- https://projekt.sweclockers.com/asus/lamna-in (submission form)
- https://projekt.sweclockers.com/asus/bidrag/exempel (example entry)

## Deadlines

- Entries are open from 16 October to 30 November. An entry can be edited until voting opens on 1 December.
- Voting runs 1 to 13 December. The winner is announced 17 December.
- The jury's documentation deadline for the top three is 15 December, 23:59.

## Structure: the entry is a form, not a free post

The text goes into fixed fields with character caps:

| field | cap |
|---|---|
| Rubrik | 120 characters |
| I en mening | 160 characters |
| Vad byggde du, och hur? | 8 000 characters |
| Vad gick fel på vägen? | 4 000 characters |
| Modeller och verktyg | 500 characters |
| Hårdvara | 300 characters |
| Var kördes AI:n | one choice: Helt lokalt / I molnet / Båda och |
| Tokens bearbetade lokalt | a number |
| Tokens betalda i molnet | a number |
| Hur du fick fram siffran | one choice: Från en tokenräknare / Uppskattat / Verktyget visar inga tokens |
| Bilder | 1 to 10 files |
| YouTube | optional |
| Projektlänk | optional; a live URL or the source code (e.g. GitHub) |
| E-post, namn (an alias is allowed), SweClockers-användarnamn | e-mail required and not public; name required and public; username optional |
| Declaration | accept the terms; the work is your own and you can prove it |

The overview page says the failures along the way are what readers learn most from, so "Vad gick fel" is a core section.

Neither page says whether the fields render Markdown. inlagg.md is therefore split by form field, and the image markers in it show placement only.

## Images

- Between 1 and 10 images.
- PNG, JPG, WebP or GIF, up to 5 MB each (lamna-in).
- The images are uploaded through the form, so no external hosting is needed.
- If a person appears in an image, they must consent to publication.
- The terms set no rule on pixel dimensions.

## Eligibility

- Entrants must live in Sweden and be 16 or older. Under 18 needs a guardian's approval.
- Staff of SweClockers, the sponsors and the co-organisers may not take part.
- One entry per person. Several addresses that reach the same inbox count as one person, and disposable addresses are not allowed.

## Content requirements

- **The AI work must be done during the contest**, "från 16 oktober". Older material is allowed, such as an unfinished hobby project, but the entry must clearly show what existed before and what was done during the contest.
- The entry must be in Swedish.
- The work must be your own. Building on other people's models, tools, libraries and open-source code is allowed, but the entry must state what was used.
- **Tokens must be reported:** local and cloud separately. A subscription without a counter (the page names Claude Pro as an example) needs an estimate marked with ≈ and a short description of the method. The organiser can ask for evidence, and an obviously wrong figure can lead to disqualification.
- The top three must show token evidence, prove authorship (the organiser's personal code placed in the project, e.g. in a commit or the README), and show when the work was done. Accepted evidence includes GitHub history.

## What the entry must not do

- Infringe anyone's IP or break SweClockers' rules.
- Cheat with votes, authorship or tokens.
- Vote for your own entry.
