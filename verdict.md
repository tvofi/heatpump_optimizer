## Block

- The new bridge (`HeatEnergyMeter.bridges_hot_water`, through `replay_gate`) keeps a counter span clean across a cycle in which the dwell observed a hot-water charge. The close-side subtraction in `heat_energy.span_heat` only runs under `ev.attribution.observed and ev.attribution.dhw > 0.0`. The span's attribution is `dwell.shares(start, end)`, which is `None` (plan split, `observed=False`) once **any** segment of the span is unobserved. That happens on a single mode read that is not live, including a last-good read inside its age limit (`observed_duty(..., live=False)` is None), or on an unseen same-duty excursion. In that domain `span_heat` falls through to `space_heat_kw(..., integrated=True)`. With the plan's hot-water hours at 0, that function's whole-unit rule returns the **entire** span heat as space heat, the bridged charge included. In the same span `SpanEnergy.dhw_kwh` is `None` ("unaccounted steps ... read no space figure", in the diff's own comment), but nothing reads it, because the guard requires an observed attribution.
- Reproduction (reviewer's harness `ev/unobs_span.py`, output `ev/unobs_head.txt`): 12 half-hour reads, 1 kWh per space step, a 5 kWh charge that the dwell observed. All observed: `space_kw=1.818` (correct: 10 kWh/5.5 h, dhw_kwh=5.0). Mode read at cycle 6 not live: `space_kw=2.727`, dhw_kwh=None, observed=False, so the whole 15 kWh is read as space heat (+50 %). Null control: no charge with the same unobserved read gives `space_kw=2.0 = heat_kw`.
- Reachability: the unobserved cycle stays clean at the per-cycle gate. `_close_fabric_interval`/`_interval_space_power` (coordinator.py 4979-5033, 5664-5697) check neither `mode_live` nor an unobserved dwell, `ran_hot_water` is False when unobserved, and no `_learning_frozen` key names the mode entity, so `replay_gate` returns clean. The bridged cycle is clean by this diff (feature check arm 1). At the merge base 6f0ff9d8 the charge cycle has no interval and no bridge, so the span was unclean and never replayed. The over-read therefore reaches the house and lower-floor heat-loss learners only because of this diff.
- Fix direction (the fixer's call): when the span carried a bridged cycle, the span must not use the whole-unit/time rule. For example, refuse a space figure whenever `e.dhw_kwh` is None or positive and the attribution is unobserved, or track "bridged" on the meter and gate on it. Pin it with a span that has one non-live mode read.
