## Block

`tools/audit/seat/prune_refs.py` `apply_plan_push` (new in this PR, called by `closeout.py` step 2 and by `prune_refs.py --apply`/`--topic --apply`) pushes `git push --delete refs/heads/<name>` with no lease. The only guard, the missing-tag read-back, compares the remote's archive tag with the sha *the plan read*, not with the ref's tip at delete time. Its own docstring and `closeout.py`'s header promise "a ref to delete without its tag at its own sha refuses the whole step before any delete". That promise does not hold for a ref that moves between the plan read and the delete push: the ref is deleted and its new tip is archived nowhere. For a ref the plan deletes untagged (`ci-probe/*`, a tip in main), the new commits are archived nowhere at all.

Reproduced at this head with the module's own function against a throwaway bare remote (ev/lease-race.py, ev/lease-race.txt): plan at a1484914, ref advanced to 96965aa6, `apply_plan_push` returns `tag` and `delete`, the remote ends with no `fix/x` head and `archive/fix/x` at a1484914 only. `RESULT moved-tip-deleted-untagged=1`. Null control (ev/lease-null.txt): the same plan taken at the live tip archives and deletes with nothing lost, `RESULT ... moved-tip-deleted-untagged=0`. Candidate fix, tested on a copy (ev/lease-fix-candidate.txt): one `--force-with-lease=refs/heads/<n>:<planned sha>` per ref in each delete chunk; the moved ref is rejected (`delete-FAILED`, the chunk aborts as the arm already does on a refusal) and survives at 96965aa6, `RESULT moved-tip-deleted-untagged=0`. The repair owes a self-test arm that plants the moved ref and fails without the lease, plus a mutant that drops it.

The old gh-api arm (`apply_plan`) had the same unconditional DELETE. The push arm is new code written for this group's carry 3, though, and its archive-first guarantee is the property the owner's request rests on, so this is a block on the new arm and not only a carry. `--topic --apply` runs mid-round, while seats still push, so the window is not confined to the round's last act.
