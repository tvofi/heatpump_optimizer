- [#1621](https://github.com/tvofi/heatpump_optimizer/pull/1621) — **merged `c182e1cb`**, Switches: show a toggle at once instead of after the next solve. Fixes bug 5 of tvofi's v6.6.12 report ("Away, boost DHW, optimizer active and boost space heating ... flip back on in a few seconds") for the "can not be switched back off" half: each entity reads live state and publishes it before the refresh starts, taking `refresh=False` setters and a background-task refresh so HA's toggle fallback never overwrites a fresh write. **Owed work**: this PR does not explain the other half of bug 5, "all toggles on after reboot" — the PR body's own check of every writer of `held.until`, `override_active` and `_mode` at startup did not find the cause, and it remains unexplained. Separately, a mode change is persisted only at the end of a completed update cycle: a restart or a failed cycle before that point restores the old mode rather than the one in progress, which is a plausible contributor to the reboot symptom but is not confirmed as its cause.
