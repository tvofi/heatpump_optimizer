## Why it matters

The coordinator's private attributes are a de-facto API that no seam map, metric or type describes:
- A rename breaks a collaborator only when a test happens to drive it.
- A coordinator seam move has to carry every out-of-class reader.
- A write from outside, such as `boost.apply` setting the running action, is a state transition with no owner.

The ratchet does not see any of it (sibling issue, arm (b)).
