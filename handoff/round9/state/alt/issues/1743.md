## Shape

- **One planner class** in a new module, built per solve from explicit inputs and passed down. It writes no attribute.
- **Return values replace the stashes.** `_build_dhw_requirements` returns the plan and the requirement; the optimizer keeps `_dhw_requirement`, preserving last-writer-wins. `_dhw_legionella_step` is deleted. `DhwPlan` keeps exactly its published fields, which `tests/features.py` pins.
- **Shared helpers move without a cycle.** `_step_humidity` and `_mean_humidity` go to `thermal_model.py`; `_pin_is_free` goes to `manual_plan.py`.
- **The horizon parameter** is typed by a Protocol, never an `if TYPE_CHECKING:` import, which would add an equivalent guard the count ratchet refuses.
- **Tests:**
  - 42 direct calls, 16 monkeypatches and 8 captures in `tests/features.py`, plus `tests/guard_pins.py:134`, retargeted with no delegating shims;
