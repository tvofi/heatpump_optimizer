_Requested by **tvofi**_

Fixes #1688, Fixes #1675, Part of #1668, Part of #1645, Part of #201.

Six config-text / translation defects in `strings.json`, `translations/en.json`,
`translations/sv.json` and `icons.json`: a double-escaped unicode sequence, a
missing icon block for every registered service, nine bare-unit help texts, a
mistranslated entity name, and two overclaiming strings (a curve-bias figure
and a quick-setup field description). No production `.py` file changes.

**Before:** the hot-water-minimum error text showed a literal backslash-u
escape instead of `°C` (and, in Swedish, 9 more garbled characters); none of
the 12 registered services had a services-picker icon; 9 help-text leaves
wrote bare `45 C` / `60 C` / `20 C` / `W/m2` beside selectors that already
render `°C` / `m²`; the Swedish name of the Sensor-Gap Advisor sensor read
"sensor gap in the currency"; the curve-learning description claimed a
0.5 K/week cap the model can exceed (measured worst case: 0.6 K); the
quick-setup buffer-tank field said the tank "stores cheap heat and releases
it during expensive hours" unconditionally, which is only true once a
throttling mixing valve is also configured in Options (`thermal_model.py`'s
`buffer_is_store` requires both).

**After:** all six are worded correctly, matching the convention the rest of
each file already uses (real UTF-8 characters, not JSON escapes; the shared
`°C`/`m²` unit style), and the buffer-tank text now states the mixing-valve
precondition instead of promising unconditional savings.
