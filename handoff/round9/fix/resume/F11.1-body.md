  mode (used only when `fetchPullsBySha` cannot reach the API at all) still
  reads the squash shape alone; this PR deliberately did not widen it,
  because that fallback's zero is a "could not enumerate" signal
  (`enumSkipLine`) and widening it changes what a zero there means. F11.4's
  agreement lane should register this as a known, accepted difference rather
  than a third reader to reconcile.

  `origin/main` in to re-measure against current main, then reverted that
