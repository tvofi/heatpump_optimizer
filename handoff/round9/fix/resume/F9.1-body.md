## Friction

`gate-scoping.md: unenforced: a "light in-memory mutant check" script
that copies the package and mutates a temp file must run its subprocess
from a cwd with no custom_components/ of its own -- Python's implicit
sys.path[0] = '' (cwd) resolves the REAL repo's package ahead of any
PYTHONPATH entry when the mutant runner's own tempdir happens to be
under, or otherwise expose, a custom_components/ directory, silently
testing the wrong (real, unmutated) copy for both the "baseline" and
"mutant" runs. Cost seen here: one full re-derivation of all five
mutant proofs after the first pass silently reported no difference for
one of them. No standing check exists for this because the helper
script is throwaway per PR, not a tracked instrument; noting it so the
next test-pin lane fixer does not lose the same cycle.`
