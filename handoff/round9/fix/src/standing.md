**Mac-local lanes (standing, tvofi 2026-09-27).** On the Mac, run the typing lane (`python3 tests/typing_ruler.py --mypy`) and the mutation/pin lanes (`tests/mutation_table.py`) inside the `hpo-ci` Linux container (`docker exec -e PYTHONPATH=/repo/tests/hastub hpo-ci python tests/<script>.py`; setup script `/Users/timmalmstrom/macfloat-fix/.container-setup.sh`). Both lanes have Mac-invisible failure modes, proven 2026-09-27: the typing toolchain lock installs only on Linux wheels, and the pin lane needs the Linux float baseline to get past the Mac-local features red. Record closures in the container too (it is Linux, which `gate-scoping.md` requires); `PREPR_SKIP_CLOSURES=1` is the fallback only when the container is unavailable, and the PR body says which route ran. Container use is serialized through the repo's own lease mechanism: take the seat's lane lease HOST-SIDE: `tests/gate_lock.py auto-lease --label <seat-lane> -- docker exec ...` from the Mac, where its lock file is a different file from the container's own lease (tvofi, 2026-09-27). NEVER wrap a lease inside the container around `./tests/run.sh` — run.sh routes stress.py through the same single-owner lease and the nesting deadlocks on itself. Never wrap anything but `docker exec`: a host wrap around a NATIVE `./tests/run.sh` deadlocks at once and invisibly (run.sh renews the wrapper's own label, then blocks on the wrapper's flock — no ticket, no timeout; measured). Never set `HPO_GATE_LOCK_DIR` under `/Users` for a lane and never pass `-e HPO_GATE_LOCK_DIR` (or `-e HPO_GATE_LOCK_LABEL`) into the container: `/Users` is bind-mounted at the same path, so that makes host and container lock file one file and the nesting deadlock returns (measured: a silent 30-minute wait, then permanent). A lane over 1800 s may run under auto-lease anyway — the wrapper never renews and its lease is fixed, but flock, not the lease, excludes, so a lapsed lease costs only truthful `status` output; for honest bookkeeping hold the lease manually (`take --lease-seconds N`, renew between commands — the judge_batch shape) or split the lane. The host lease is convention, not enforcement: skipping it degrades the shared 4-CPU VM's throughput; the container's own lease still serializes every stress.py run (recorded decision 2026-09-27: no check built). The VM behind the container has 4 CPUs shared by every container, and concurrent gate stacks contend to a standstill.

**Resumability (tvofi, 2026-09-26 19:05Z).** Assume this session can crash at any moment, and lose at most the last half hour.

- **Push at every step boundary.** Commit and push `HEAD:refs/heads/<your branch>` (read `git ls-remote` back) when the failing test is written, when the fix is green, when the body is drafted, and in any case at least every ~30 minutes of work. Never hold unpushed work across a long run (a gate run, a stress run, a subagent). A reviewer does the same on `<branch>-review`; a runner or subagent pushes its outputs, or hands them to the seat that pushes, before it reports.
- **Keep the resume note.** On your branch, `handoff/round9/fix/resume/<PR-id>.md` (a reviewer: `<PR-id>-review.md` on the review branch) holds: last completed step, next step, `branch@commit`, merge base, open questions, and what is waiting on whom. Update it in the same commit as every push. It outranks the roster for in-flight state.
- **Log milestones.** At each milestone (branch cut, failing test, green, body drafted, hand-off, review verdict, merge) append one dated line to `/mnt/project-files/audit-r9/RESUME.md` and the same line to its mirror, `handoff/round9/RESUME.md` on `handoff/audit-r9-plan` (fetch, append, commit, push; on a non-fast-forward, re-fetch and re-append; never force). A Mac seat, which cannot read `/mnt/project-files`, writes the mirror only; the orchestrator copies mirror lines into the `/mnt` log at its next pass.
- **Restart, do not redo.** A crashed seat is restarted from its branch and resume note: fetch the branch, check the note's commit against the fetched head (if the branch is ahead, trust the branch and its log), `git merge origin/main` if main moved and re-run `fixer.md` steps 2-8, then continue at the note's next step. The roster's `resume` field for each PR names its branch, note file, review branch, and the exact cloud and Mac pickup commands; FIX-PLAN.md section 11 says the same for the whole plan.
