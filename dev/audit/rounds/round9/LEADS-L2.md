## Finding

### D8-s3-61 (low, D8.M4, class guess P2): Valve Target Recommendation ships disabled where a mixing valve is set, and available-but-unknown where none is

- Claim: In 5 of 5 golden topologies with mixing_valve_mode=manual, Valve Target Recommendation publishes a target (23.0 °C) and its reason while its registry default is off; in the same 5 topologies without a valve it is available with state unknown.
- Mechanism: ValveTargetRecommendationSensor keeps a static _attr_entity_registry_enabled_default=False and the base availability, while the payload key it reads (coordinator._mixing_valve_view) exists only when mixing_valve.is_throttling(mode). Its sibling opt-in readouts take default and availability from the configured feature: ConfiguredInputMixin (ECL110, probes; #1302/#1542) and DHWEntityMixin (#1398). The class docstring's reason ('disabled rather than eternally-unknown') covers only the no-valve install, where the entity is nevertheless available.
- Metric: Topologies (of the 5 golden coordinator scenarios) with mixing_valve_mode=manual where the entity's native_value is not None and entity_registry_enabled_default is False.
- Evidence: `PYTHONPATH=tests/hastub /home/claude/venv314/bin/python tools/audit/round9/D8/leads/l2_d8_leads.py --only D` gives `RESULT valve_value_but_default_off=5`, `valve_unknown_available_no_valve=5`, exact; load1 1.94, thread_factor 1.000.
- Instrumented symbol: `heatpump_optimizer.sensor:ValveTargetRecommendationSensor (entity_registry_enabled_default, available, native_value) over heatpump_optimizer.coordinator:HeatPumpOptimizerCoordinator._mixing_valve_view`
- Perturbation: --perturb valve: entity_registry_enabled_default follows mixing_valve.is_throttling(config mixing_valve_mode) (in memory), which gives 0 (observed).
- Property: An entity whose value exists only under an opt-in configuration feature takes its registry default and its availability from that feature being configured, never from a static class attribute.
- Seam rule: `grep -n '_attr_entity_registry_enabled_default = False' custom_components/heatpump_optimizer/sensor.py custom_components/heatpump_optimizer/binary_sensor.py  (each hit checked against the payload gate its value needs)`
- Fix scope: Gate ValveTargetRecommendationSensor's default and availability on mixing_valve.is_throttling(mode) in the ConfiguredInputMixin shape; update README.md:551/:560 and the disabled-set pins in tests/entities.py. Existing registry entries keep their state.
