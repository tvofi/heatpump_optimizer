# D15 — Debugging run from a live diagnostics bundle

Owner's ask (#1938): *a debugging run from a diagnostics data export*.
tvofi's ruling of 2026-10-14 overrides decision 0012's moratorium for this
file. Read `COMMON.md` first.

**Inputs**, at absolute paths outside every tree, named in your task:

- **Primary:** the "Download diagnostics" file's `debug` bundle with its
  replay half filled (past `INLINE_CAP_BYTES`, the `.storage` copy too).
- **Until the R10-DIAG-REPLAY group lands** (`DebugCollector.async_bundle`
  leaves `replay` null): `tools/replay/export.py` output from the same box
  and window, beside the download.
- **Null control:** `tools/replay/dbg_bundle_gen.py`'s synthetic bundle;
  every step runs on it first.

**No real bundle: every step `unfinished`, no finding**; a synthetic-only
anomaly is a lead.

## Method

1. **Intake and version seam.** Unwrap `debug`. `integration_version` is the download's, not each row's. The owner installs each release on its release, so a cycle ran the newest release tag dated before the last restart gap in `cycle_rows[].t` preceding it (tag dates from `git for-each-ref refs/tags`). Every seat attributes each anomaly so and re-checks it at the baseline; old-version-only is a non-finding, with evidence. A gap is host downtime, not a lead, unless the bundle shows the integration running through it.
2. **Privacy gate.** `tests/replay.py`'s `LEAK_PROBES` controls green, then `export.violations` over the bundle with a planted-credential arm; either failing stops the run.
3. **Ingest.** `tools/replay/debug_ingest.py --bundle`; `--corrupt accuracy` is its perturbation; a check passing on an empty section is vacuous.
4. **Store replay.** Each store document through its loader and `store._sanitize` against `store.DOMAINS`: quarantined leaves, refused versions.
5. **Timeline replay.** `tools/replay/debug_replay.py --bundle`, stores seeded, over the replay half: the lane's judges, offenders per cycle.
6. **Monitor re-run.** Bias and MAE per window, stated; `Cusum` and `SnapshotRing.observe_bias` against the recorded `accuracy_drift` latch.
7. **Row scan.** `cycle_rows` and `payload_snapshots`: solve failures, `solve_wall_ms` outliers, stale feeds, action against plan, each self-test re-derived.
8. **Anomaly to seam.** Each step-7 anomaly to its `tests/seam_map.json` seam, reproduced by `debug_replay.py --start/--end` over its window, with the perturbation that moves it.

**The bar.** The replay judges, `debug_ingest.py`'s checks and each step's
re-derivation are the graders. A finding is real-bundle-only, re-run by one
command against the bundle path, and moves under its perturbation.

**Privacy.** No bundle value is written unless `export.violations` passes it.

**Out of scope.** Store fuzzing (D1), missing tests (D3), class detectors
(D14): leads. Fix-phase lead: each cycle row should record the version
that wrote it.
