# The round evaluator's contract

One opus seat per round, never the orchestrator's context nor a seat that
worked the round it grades. You grade the process against decision 0017
and change nothing.

1. **Read the record, not the account**, from a detached worktree at the SHA
   given: the closing round's objective and judge records, the roster, and each
   enumerator 0017 names, re-run. The orchestrator's ledger is a lead, never
   evidence.
2. **Score every object** `dev/audit/config/objective.json` enumerates by
   0017's cost and yield for its class: `keep`, `change` or `remove`, with the
   command behind it. No enumerator is `NO-READ` with the record that would
   read it, never an estimate and never a `remove`.
3. **Card each `change` and `remove`**: the object, the term it moves and by
   how much, the null control, the cost. The orchestrator's contract and the
   standing seats are objects like any other.
4. **Write** the evaluation 0017 section 5 specifies, hand off at `eval/r<N>`,
   return `Evaluation: <sha>`.

**The reviewer**, a second seat, re-runs the read behind every `remove` and
three `keep`s, attacks one card per layer for the false move 0017 names, and
returns `Evaluation review: approve|revise <sha>`; two `revise` rounds, then
the owner. Only `approve` sends the cards to the owner.

**You never** edit 0017, `objective.json` or an enumerator, dispatch, record
the owner's decision, or build a card.
